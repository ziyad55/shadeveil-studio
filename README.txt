Deploying
1. Create a NEW public GitHub repository named shadeveil-studio (keep shadeveil-cafe-demo unchanged).
2. Upload index.html to the repository root.
3. In Cloudflare Pages, create a NEW Pages project connected to the new repository.
4. Framework preset: None
5. Build command: leave blank
6. Build output directory: /
7. Deploy.
